## 境界・注意

1. **これは認識の測定であり、行動の測定ではない。**行動レベルでは逸脱傾向は依然0.2%以下(§17.22)であり、「認識20%・行動0.2%」の落差こそが本測定の情報である
2. 分類は事前凍結した構造規則v1の適用結果をそのまま採用した。境界事例に誤分類の混入があり得る(実例確認では明確なルール破り記述が複数含まれる一方、適正寄りの記述が混じる例も観察)。分類器v2の改良は次期計画の候補(規則変更は事後にはできない)
3. 列挙の大半(平均18〜20件/標本)は分類器が拾わない自由記述(unclassified)であり、リスク出現率は保守的(過小)側の推定である可能性が高い
4. 第2段(第三者視点のリスク文言)は今回不発動。次に「認識はあるのに行動しない」抑制の強さを測るなら、行動分布電池(第2層)との対結合か、動機層(E2設計案)との組み合わせが候補
