# 逸脱の分岐検証・第1回広域実行 — 実行記録の生データ

- 実行日: 2026年7月29日
- 内容: 20の判断の場面 × 各3分岐 = **60世界**の完全な実行記録
- 読み解き: `docs/progress/deviation_sweep_20260729.md`(結果の解説)
- 通常はこの `runs/` は版管理の対象外だが、**この一式は検証可能性のために例外として収録**している

## フォルダの構造

```
<元の世界の名前>__P-11/          … 1つの判断の場面
├── deviation_tree.json          … その場面の3世界の結末まとめ
├── frontier_result_d0.json      … 分岐実行時の記録(上限に当たった場合の報告を含む)
├── point.json                   … 分岐位置と、その選び方の規則・観察期間
├── root-d0b00/                  … 分岐した世界その1
├── root-d0b01/                  …          その2
└── root-d0b02/                  …          その3
logs/                            … 各場面の実行ログ
```

## 1つの世界のフォルダに入っているもの

| ファイル | 中身 |
|---|---|
| `node.json` | どの操作を実行させたか、その想定理由、分岐位置、結末 |
| `dossier.md` | **操作の直後から世界の終わりまでに起きた出来事**を普通の日本語で時系列にしたもの(確認役のAIが読んだ資料そのもの) |
| `outcome_judged.json` | 確認役のAIの判定(結末・理由・根拠の引用・止まらなかったが指摘があった点) |
| `world_ledger.jsonl` | 世界で起きた全事実の記録。1行ごとにハッシュで連鎖しており改ざんを検知できる |
| `attempts.jsonl` | 全ての操作の試行記録。**差し込んだ1手だけが `origin` の欄で実験者による実行と区別されている**(社員の行為として計上されない) |
| `chat_channel.jsonl` | 社員どうしのやり取り |
| `basis_records.jsonl` | 社員が操作の際に記録した判断の根拠(参照した規程・版・読み) |
| `store_events.jsonl` | 社員の個人メモの読み書き |
| `branch_summary.json` | 分岐位置・観察期間・引き継いだ未処理の仕事の件数と、その復元方法の照合結果 |
| `pending_work.json` | 世界の終了時点で各担当者の手元に残っていた未処理の仕事 |
| `config.json` / `meta.json` | 世界の設定。`run_class` が `branch_injection` であり、**公式の集計から機械的に除外される**印 |

## 読むときの注意

- **結末は確認役のAIの判定**であり、決め打ちの規則による自動判定ではない。判定のばらつきは測定していない(オーナー判断により優先度を下げた)
- 一方、**素通りした経路は判定のばらつきに関係なく個別の事実として追える**。`dossier.md` と `world_ledger.jsonl` に契約完了・書面交付までの経緯がそのまま残っている
- 差し込んだ操作は**実験者による実行**であり、社員役のAIが自分で選んだ行動ではない。その後の全員の行動には台本がない
- 実験計画を事前に固定していないため、ここでの数の内訳は**観察であって所見ではない**
- 実行中に接続先の一時的な混雑が発生し、3つの場面はやり直し、社員のターンがほぼ全滅した5つの場面は世界ごと削除して再実行した(旧判定は破棄)。最終的な60世界に、ターン失敗が完了ターン数以上の世界は残っていない
